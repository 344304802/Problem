## 问题3：两工况对比与优先级

### 高浓度工况(工况4)

- $$C_{in} = 44.64$$ g/Nm³, $$T = 121.1$$ ℃
- $$U = ['45.9', '45.4', '65.1', '58.1']$$ kV, $$T = ['173', '171', '366', '457']$$ s
- $$P = 1489.6$$ kW, $$C_{out} = 10.00$$ mg/Nm³

### 低浓度工况(工况1)

- $$C_{in} = 25.98$$ g/Nm³, $$T = 121.1$$ ℃
- $$U = ['45.9', '45.4', '65.1', '59.8']$$ kV, $$T = ['219', '159', '428', '377']$$ s
- $$P = 1493.0$$ kW, $$C_{out} = 10.00$$ mg/Nm³

### 差异原因

- 高浓度工况(工况4, C_in=44.64)需更高电压承担除尘负荷
- 高浓度工况总振打周期 1166s < 低浓度工况 1183s, 需更频繁清灰
- 高浓度工况下粉尘负荷大, 极板积灰快, 需缩短振打周期并提高电压维持效率
- 低浓度工况下粉尘负荷小, 可适当降低电压省电, 延长振打周期减少机械磨损

### 优先级判定

$$\text{电压性价比} = 0.761437$$
$$\text{振打性价比} = 0.000000$$
**结论: 优先调电压**

## 高浓度工况(工况4, C_in=44.64 g/Nm³)应对建议

### 电压调整方向
- 第1电场电压基本不变
- 第2电场电压需提升 2.44 kV (从 45.40 → 47.84)
- 第3电场电压基本不变
- 第4电场电压需提升 5.89 kV (从 58.13 → 64.02)

### 振打周期调整方向
- 第1电场振打周期基本不变
- 第2电场振打周期基本不变
- 第3电场振打周期基本不变
- 第4电场振打周期基本不变

### 多电场协同策略
- 前电场(1-2)承担主要除尘负荷, 优先提升电压
- 后电场(3-4)精细控制, 维持低排放的同时尽量降低电压省电
- 高浓度工况下振打周期应整体缩短, 防止极板积灰导致效率骤降
- 若电压已达变压器上限仍不满足5 mg/Nm³, 需考虑硬件改造(增加电场数或提升变压器容量)
