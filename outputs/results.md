## 问题3：两工况对比与优先级

### 高浓度工况(工况0)

- $$C_{in} = 44.34$$ g/Nm³, $$T = 119.5$$ ℃
- $$U = ['45.9', '55.0', '71.0', '69.8']$$ kV, $$T = ['233', '233', '445', '445']$$ s
- $$P = 1760.8$$ kW, $$C_{out} = 10.00$$ mg/Nm³

### 低浓度工况(工况5)

- $$C_{in} = 26.01$$ g/Nm³, $$T = 120.8$$ ℃
- $$U = ['45.9', '45.6', '71.0', '69.8']$$ kV, $$T = ['233', '233', '445', '445']$$ s
- $$P = 1654.7$$ kW, $$C_{out} = 10.00$$ mg/Nm³

### 差异原因

- 高浓度工况(工况0, C_in=44.34)需更高电压承担除尘负荷
- 高浓度工况总电压 241.8kV > 低浓度工况 232.4kV
- 高浓度工况总振打周期 1356s < 低浓度工况 1356s, 需更频繁清灰
- 高浓度工况下粉尘负荷大, 极板积灰快, 需缩短振打周期并提高电压维持效率
- 低浓度工况下粉尘负荷小, 可适当降低电压省电, 延长振打周期减少机械磨损

### 优先级判定

$$\text{电压性价比} = 18.095390$$
$$\text{振打性价比} = 0.000000$$
**结论: 优先调振打**

## 高浓度工况(工况0, C_in=44.34 g/Nm³)应对建议

### 电压调整方向
- 第1电场电压基本不变
- 第2电场电压需提升 9.70 kV (从 55.04 → 64.74)
- 第3电场电压基本不变
- 第4电场电压基本不变

### 振打周期调整方向
- 第1电场振打周期基本不变
- 第2电场振打周期基本不变
- 第3电场振打周期基本不变
- 第4电场振打周期基本不变

### 多电场协同策略
- 前电场(1-2)承担主要除尘负荷, 优先提升电压
- 后电场(3-4)精细控制, 维持低排放的同时尽量降低电压省电
- 高浓度工况下振打周期应整体缩短, 防止极板积灰导致效率骤降
- 若电压已达变压器上限仍不满足5 mg/Nm³, 需考虑硬件改造(增加电场数或提升变压器容量)
